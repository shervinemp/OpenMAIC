OpenMAIC data export

This page runs at http://localhost:3000 and reads this origin's browser storage (IndexedDB + localStorage) — the browser origin where your previous OpenMAIC sessions stored data. It packs everything into one JSON file you can import into OpenMAIC running on another port (e.g. http://localhost:3001/migrate).

Nothing leaves this machine and nothing is uploaded anywhere: the file downloads to your disk.
